# Playlist Duration for YouTube™

YouTube の再生リストの合計再生時間を、再生リストのページに表示する Chrome 拡張機能です。

## 特徴

- 再生リストを開くと、読み込まれている動画の再生時間を合計して、ヘッダーに表示します。
- YouTube は再生リストの動画を 100 本ずつ読み込みます。「すべて読み込む」ボタンを押すと残りの動画も読み込み、リスト全体の合計を出します。読み込みはボタンをもう一度押すと止まります。
- 「後で見る」などの自分の再生リストと、ほかの人が公開している再生リストの両方で動きます。
- YouTube の中でページを移っても、再読み込みなしで再生リストのページに表示します。
- 表示の文言は、Chrome の表示言語が日本語なら日本語、それ以外は英語です。

## 制約

- 合計するのは、ページに読み込まれている動画だけです。動画が 100 本を超える再生リストでは、「すべて読み込む」を押すまで最初の 100 本の合計になります。
- 再生時間が表示されない動画（配信中のライブ、非公開や削除済みの動画）は、0 秒として数えます。
- ウィンドウの幅が 1080 ピクセル以下のときは表示しません。
- YouTube の画面の作りが変わると、表示されなくなることがあります。

## インストール方法（開発者モード）

1. このリポジトリをクローンまたはダウンロードします。
2. 依存関係をインストールします。
   ```bash
   npm install
   ```
3. プロジェクトをビルドします。
   ```bash
   npm run build
   ```
4. Chrome で `chrome://extensions` を開きます。
5. 右上の「デベロッパー モード」をオンにします。
6. 「パッケージ化されていない拡張機能を読み込む」をクリックし、プロジェクト内の `dist` フォルダを選択します。

## 開発用コマンド

- `npm run build`: プロジェクトをビルドし、`dist` ディレクトリに出力します。
- `npm run dev`: ファイルの変更を監視して自動でビルドします。
- `npm test`: テストを実行します。
- `npm run typecheck`: 型検査を実行します。
- `npm run clean`: `dist` ディレクトリを削除します。
- `npm run zip`: ビルドして `dist` ディレクトリを `extension.zip` に圧縮します。

## 仕組み

YouTube はページを再読み込みせずに画面を切り替えるので、コンテンツスクリプトは YouTube の全ページで読み込み、`yt-navigate-finish` イベントで今のページを確かめます。再生リストのページ（`/playlist`）にいるあいだだけ画面の変化を監視し、それ以外のページでは何もしません。

再生リストの行には 2 種類の作りがあります。自分で編集できる再生リストは `ytd-playlist-video-renderer`、それ以外は `yt-lockup-view-model` です。`src/playlist.ts` は両方を読みます。再生時間はサムネイル上の表示から読み取ります。YouTube はマウスを重ねた動画の再生時間の表示を消すので、最後に読み取った値を動画ごとに覚えています。

外部との通信はありません。計算はすべてブラウザの中で行います。
